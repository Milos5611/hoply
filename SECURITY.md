# Security

Please report security problems privately by email to **coolcraftcoders@gmail.com**, not in a public issue or pull
request. Say what you found, how to reproduce it, and which Hoply version you ran (Settings → Updates shows it).

Examples of what counts: a way for anything other than a process on your Mac to reach Hoply's listener, a request to
the listener that reads or writes files, a Keychain secret showing up in settings, logs or URLs, an update that
installs without a valid signature, or Clean up or Stop touching something it shouldn't.

Fixes ship as a new release, which installed copies pick up through their update check.
